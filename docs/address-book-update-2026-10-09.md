Миграция применяется один раз при запуске после инициализации базы данных.
Она исправляет только известные старые записи, сохраняет их ID и заметки,
добавляет отсутствующие записи из источника и сохраняет остальные пользовательские записи.
Предыдущие версии исправленных строк сохраняются в address_book_revisions.previous_entries_json.
Все изменения выполняются в одной транзакции; конфликт откатывает транзакцию.
Повторный запуск не затрагивает последующие правки администраторов.

Деплой подтверждает наличие всех 982 записей через существующий защищённый POST /api/deploy
с JSON {"verifyOnly":true}. Требуется прежний секрет деплоя. Содержимое книги и резервной копии
этот запрос не возвращает. GitHub Actions ожидает перезапуска и проверяет результат миграции.
