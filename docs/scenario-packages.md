# Полный перенос сценария

В разделе «Бэкап сценариев» кнопка «Скачать сценарий целиком» сохраняет ZIP-пакет. Для импорта можно выбрать этот ZIP либо распаковать его и выбрать всю папку с `scenario.json`.

В пакет входят название и описание, обложка, адреса и квартиры, признаки интернет-кафе, вопросы, варианты выбора и результаты, страницы кафе с условиями открытия, приложения с исходными файлами и номерами, а также брифинг. Сохраняются переносы строк, порядок и активность материалов. При импорте связи пересоздаются с новыми идентификаторами.

Внутри пакета есть `scenario.xlsx` для просмотра таблицы и `scenario.json` с описанием и контрольными суммами файлов. Старые `.xlsx` и `.xls` можно импортировать как раньше; они содержат только таблицы. Экспорт одной таблицы доступен через `GET /api/backup/export?scenario_id=ID&format=xlsx`.

Импорт создаёт новый неактивный сценарий. Если такое название уже существует, импорт отклоняется. Состав пакета проверяется до создания сценария; при ошибке записи созданные материалы удаляются. Игровые комнаты, участники и их прогресс в перенос сценария не входят.

Максимум: 250 МБ на пакет или папку, 10000 файлов; для одного приложения — 30 файлов и 100 МБ.

## Обновление сервера

Установите зависимости в `backend/` (`npm ci --omit=dev`) и перезапустите приложение. Для SQLite новые поля порядка и активности вопросов добавляются при запуске.

Если перед приложением стоит Nginx, примените лимит `client_max_body_size 260m` (с запасом на multipart). Шаблон `deploy/beget/nginx.conf` обновлён; действующий конфиг сервера нужно обновить и перезагрузить отдельно.

Проверка: `npm run test:scenario-package` из корня проекта. Тесты используют временные базы и папки.
