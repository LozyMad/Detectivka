# Визуальный концепт «Городское досье»

`hero-dossier-concept.png` создан встроенным инструментом генерации изображений 4 октября 2026 года. Это атмосферная иллюстрация для предложенного оформления страницы друзей. Не является снимком интерфейса, фотографией клиента или материалом реального расследования.

Использование: слева живой заголовок и кнопки; справа иллюстрация. В мобильной версии лучше расположить изображение после текстовой части. Для блока доверия и корпоративных кейсов использовать настоящие фото и материалы игры.

Финальный промпт сохранён в `hero-dossier-prompt.txt`.
